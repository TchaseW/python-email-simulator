# Python Email Simulator

## About This Project
This project is an object-oriented Python email simulator that allows users to send, receive, read, and delete emails. Each user has an inbox where received emails are stored and managed.

## Technologies Used
- Python
- datetime module
- Object-Oriented Programming (OOP)

## Programming Concepts Demonstrated
- **Classes and Objects:** Created Email, User, and Inbox classes.
- **Encapsulation:** Organized email and inbox functionality into separate classes.
- **Object Relationships:** Connected users, inboxes, and email objects.
- **Methods:** Implemented sending, reading, deleting, and marking emails as read.
- **Lists:** Stored and managed emails in an inbox.
- **Conditional Logic:** Checked inbox contents and email status.
- **Input Validation:** Prevented invalid email selections.
- **Date and Time:** Recorded email timestamps using Python's datetime module.

## Features
- Send emails between users.
- Receive and store emails in an inbox.
- View a list of received emails.
- Read full email messages.
- Automatically mark emails as read.
- Delete emails from an inbox.
- Display the date and time an email was received.
